# Данные

Датасет не копируется. Используемые manifests находятся в AR-3: train 15998, public 2000, private 2000 (всего 19998). По указанию пользователя из train исключены PMC3287911_1 и PMC2727000_2, превышавшие лимит input. JPEG и GT сохранены; остальные страницы не перенесены между splits. Для локальной проверки читается только первый ID из train/manifest.jsonl, его изображение и train GT.

Arena Example: id — исходный ID страницы; input — строка JSON с image_base64; reference — строка JSON с исходным GT. Input и reference ограничены 500000 символами каждый. Изображения не перекодируются. Закрытые public/private и их эталоны должны находиться у оператора; в кандидат, /assets и исследовательское окружение их не помещать. Решатель получает только текущий input, но не reference.

После исключения проверены только размеры JPEG и согласованность ссылок manifests: все 19998 входов укладываются в 500000 символов, максимум 465400 с JSON-обёрткой. Train-подвыборка теперь data/subsets/train-1999.jsonl в AR-3; public-500 и диагностический train-200 не изменились. GT для проверки не читался.

# Результаты baseline AR-03

Train остановлен по запросу пользователя. Ниже оценён только сохранённый
**префикс 8 476 страниц** в порядке исходного архива. Он не является случайной
или репрезентативной оценочной выборкой; результаты нельзя переносить на весь train.

Метрики в диапазоне 0–1, не проценты. TEDS — macro по страницам;
Cell F1 и Numeric accuracy — micro по ячейкам. Время — только baseline,
без чтения JPEG и оценщика. Ошибок выполнения: 0 в обоих прогонах.

Фактический wall time public с оценщиком: 95.51 с.

## Фиксированные подвыборки

- Train-2000: 2 000 страниц из 1 873 документов, seed=42. Полные группы
  документов, пропорциональные страты по числу таблиц и ячеек. Baseline на этой
  подвыборке отдельно **не запускался**, согласно просьбе остановить train.
- Public-2000 остаётся основным. Public-500 (485 документов, seed=42) сохранён
  как опциональное предложение; основной split не заменён.
- Оценка стоимости: 50 полных public-прогонов ≈ 79.6 мин;
  public-500 ≈ 23.9 с/кандидат, около 19.9 мин на 50 кандидатов.
  Это линейная оценка для данного baseline; более медленные кандидаты потребуют нового замера.
- Private не запускался и не использовался для настройки.

Manifests: `data/subsets/train-2000.jsonl`, `data/subsets/public-500.jsonl`.
Сравнение распределений: `train-2000-selection.json`, `public-500-selection.json`.

## Визуальные примеры и ограничения

[Галерея с HTML-сравнениями текста](examples/README.md).
На PMC3219649_3 структура восстановлена точно (TEDS-struct=1), но OCR ошибается
(TEDS≈0,479; Cell F1=0,2). Лучший TEDS среди оценённых train-страниц ≈0,697;
полностью правильных страниц в этом прогоне не найдено.
На PMC4683861_3 безрамочная таблица пропущена целиком.

Низкие средние оценки отражают ограничения морфологического baseline:
безрамочные таблицы, повреждённые границы, объединения и мелкий текст после
уменьшения разрешения. Это рабочая отправная точка, не качественный OCR-продукт.
Сам набор 20 000 страниц тоже отобран по порядку архивов и пригодности GT;
фиксированная train-2000 репрезентативна по выбранным признакам этого набора,
а не гарантированно по всему PubTables-1M.

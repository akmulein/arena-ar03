# Алгоритм и ограничения

Предобработка: grayscale, оценка малого наклона по Hough-линиям на копии до 600 пикселей, affine deskew,
median denoise, adaptive threshold. Морфологические opening выделяют длинные
горизонтальные и вертикальные линии; connected contours задают кандидаты таблиц.
Проекции линий задают разделители сетки. Отсутствующие внутренние границы
объединяют соседние ячейки, связными компонентами. Непрямоугольные компоненты разбиваются на единичные ячейки.
Пустые ячейки сохраняются. Каждая ячейка распознаётся Tesseract eng psm=6. Для одной таблицы
кропы передаются страницами TIFF в одном вызове; разделитель form-feed сохраняет
соответствие, включая пустые ячейки.
Пробельные последовательности нормализуются. HTML экранирует текст.

Решение специально простое: таблицы без вертикальных рамок, разорванные линии,
плотные многоуровневые заголовки и вложенные таблицы часто пропускаются или
разбираются неверно. Разрывы линий могут давать неоднозначные компоненты объединений.
Не обещается высокое качество на преимущественно безрамочных научных таблицах.
Параметры фиксированы до измерения на public. Private не измеряется.

Сложность обработки изображения в основном линейна по числу пикселей;
OCR обрабатывает отдельные кропы ячеек последовательно в одном вызове на таблицу.

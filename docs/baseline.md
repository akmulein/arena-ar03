# Baseline AR-03

## Алгоритм

Классический CPU-пайплайн OpenCV + Tesseract без обучения моделей.

1. **Предобработка:** коррекция небольшого наклона, бинаризация и обработка изображения.
2. **Детекция:** поиск кандидатов таблиц по линиям и геометрическим признакам.
3. **Структура:** восстановление строк, столбцов, ячеек и прямоугольных объединений.
4. **OCR:** распознавание текста ячеек с помощью Tesseract (`eng`).
5. **Постобработка:** нормализация текста и формирование JSON/HTML.

Реализация находится в `solution/`. Формат результата описан в `case/README.md`.

## Ограничения

Основные ошибки возникают при обнаружении таблиц, восстановлении структуры без полной сетки, обработке объединённых ячеек и OCR мелкого текста.

На диагностических 200 train-страницах TEDS = 0.122096, TEDS-struct = 0.255211. Эти страницы использовались для исправления baseline, поэтому результат не является независимой оценкой.

Baseline предназначен как простой стартовый кандидат эволюции, а не как оптимальное решение.

## Ресурсы

Исполнение на CPU. Для локального baseline используются OpenCV и Tesseract; для Arena подготовлены отдельные контейнерные окружения.

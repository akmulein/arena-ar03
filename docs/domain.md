# Обзор подходов к распознаванию таблиц

## Постановка задачи

На вход поступает изображение страницы документа с одной или несколькими таблицами. Необходимо определить границы таблиц, восстановить строки, столбцы и объединённые ячейки, распознать текст и вернуть структурированный JSON/HTML.

Задача состоит из трёх основных этапов: Table Detection (TD), Table Structure Recognition (TSR) и OCR. Ошибки ранних этапов влияют на качество последующих.

## Основные подходы

| Подход | Идея | Преимущества | Ограничения |
|---|---|---|---|
| Морфология OpenCV | Бинаризация, поиск горизонтальных и вертикальных линий, восстановление сетки | Быстро, объяснимо, не требует обучения | Плохо работает без линий, с разрывами и сложными объединениями |
| Анализ расположения текста | OCR с координатами слов, группировка в строки и столбцы | Подходит для таблиц без полной сетки | Чувствителен к ошибкам OCR, выравниванию и сложной верстке |
| Нейросетевая детекция и TSR | Модели вроде Table Transformer обнаруживают таблицы и элементы структуры | Лучше адаптируются к разнообразной верстке | Нужны предобученные веса и дополнительные вычисления |
| Гибридный пайплайн | Комбинация детекции, анализа линий, OCR и постобработки | Позволяет выбирать методы под тип таблицы | Ошибки компонентов могут накапливаться |

## Данные и оценки качества

**PubTables-1M** содержит разметку таблиц научных документов, включая координаты строк, столбцов и ячеек. В оригинальной работе предложена канонизация разметки для устранения избыточного разбиения ячеек.

В официальном репозитории Table Transformer для PubTables-1M приведены следующие результаты:
- Детекция таблиц, DETR R18: AP50 = 0.995.
- Распознавание структуры, TATR-v1.0: GriTS Topology = 0.9849.

Это результаты отдельных задач на оригинальном бенчмарке. Они **не сопоставимы напрямую** со сквозным TEDS нашего пайплайна на полных страницах с дополнительными искажениями.

## Метрики проекта

- **TEDS** — сходство HTML-деревьев с учётом структуры и текста; основная метрика.
- **TEDS-struct** — сходство структуры без учёта текста.
- **Cell F1** — точное совпадение положения, объединений и содержимого ячеек.
- **Numeric accuracy** — доля точно восстановленных числовых ячеек.

## Выбранный baseline

Морфология OpenCV → восстановление таблиц и ячеек → Tesseract OCR → JSON/HTML.

Выбран как простой CPU-пайплайн без обучения моделей. Его основные ограничения — таблицы без рамок, сложные объединения, ошибки детекции и OCR. Эти компоненты являются направлениями дальнейшей эволюции в Arena.

# DeepPavlov Arena в AR-03

Arena используется для эволюционного улучшения алгоритма распознавания таблиц.

## Принцип работы

1. Агент подготовки оформляет кейс, метрику и условия кампании.
2. Оркестратор распределяет направления поиска между исследователями.
3. Исследователи предлагают изменения алгоритма в отдельных worktree.
4. Evaluator запускает кандидатов и измеряет качество.
5. Кандидаты и их результаты сохраняются в журнале с родословной. Поиск ограничен числом предложенных решений.
6. После завершения поиска финалисты оцениваются на private.

Основная метрика AR-03 — TEDS, направление `maximize`. Решатель и метрика работают без LLM.

## Изоляция данных

| Раздел | Доступ исследователей |
|---|---|
| Train | Изображения, GT, локальные оценки и ошибки |
| Public | Только итоговый score |
| Private | Нет доступа; финальная оценка у оператора |

Метрика и разделы данных фиксируются до кампании. Решатель получает изображение через JSON, но не эталонный ответ. Кандидаты выполняются в изолированных Docker-контейнерах.

## Реализовано

- Адаптер baseline под stdin/stdout JSON.
- Программная оценка TEDS и дополнительных метрик.
- Контейнерный запуск через DockerRunner.
- `evaluator.smoke` и проверки корректного/невалидного ответа.
- `freeze/verify` замороженного пакета метрики (10 файлов).
- Подтверждён нулевой расход LLM-токенов при оценке.

Полный API submit → score и защищённая поисковая кампания пока не проверены. Эволюция не запускалась.

# Arena в AR-03

## Роли
- Агент подготовки фиксирует метрику и условия кампании.
- Оркестратор распределяет поиск между исследователями.
- Исследователи изменяют решение.
- Evaluator оценивает кандидатов.

## Выборки
- Train открыт исследователям.
- Public возвращает только score.
- Private закрыт до финализации.

## Эволюция
Кампания ограничена числом предложенных решений. Ведутся журнал, родословная,
кривая эволюции и AUC.

## Изоляция
Кандидаты исполняются в контейнерах и обмениваются JSON через stdin/stdout.
Метрика заморожена; при оценке LLM-токены не расходуются.

## Проверки
Пройдены: `evaluator.smoke`; DockerRunner → baseline → evaluator; идеальное
предсказание (TEDS=1); невалидный JSON (score=0); реальная train-страница
(валидный ответ, TEDS=0); `freeze/verify` (10 файлов). LLM-токенов при оценке — 0.

## Статус
API submit → score ещё не проверен. Эволюционная кампания не запускалась;
подготовка реальной кампании не завершена.

# AR-03 — условия основной кампании

Существующие выборки: train 500, public 200, private 200; состав, порядок, изображения и эталоны не изменяются. Исходный аудит подвыборок переиспользуется без повторного запуска; его review_required сохраняется как примечание, отдельного согласования интеграция не требует.

Единственный score — среднее page TEDS по исходной формуле, maximize, диапазон [0, 1]. Detection Precision/Recall/F1, TEDS-struct, Cell F1 и Numeric accuracy служат диагностикой; учитываются время и ошибки. Составная метрика запрещена.

Разрешён будущий поиск геометрических и алгоритмических эвристик, предобработки, постобработки, адаптивных параметров, восстановления структуры и OCR. Обучение и дообучение весов запрещены на протяжении проекта. Замена предобученных моделей и существенные новые зависимости требуют согласования. Кандидатский код выполняется только штатным изолированным DockerRunner Arena на CPU, native fallback запрещён. MPS разрешён только для локального запуска доверенного baseline, без обхода ограничений песочницы.

Codex работает через подписку ChatGPT. Hermes, внешние модельные API и MLflow не подключаются. Public раскрывает агентам только агрегированный TEDS, private — разрешённый статус. Подробные закрытые артефакты создаются операторским генератором из сохранённых предсказаний без инференса и никогда не передаются агентам. Физическая изоляция требует отдельного операторского контура, недоступного текущим инструментам Codex и контейнерам кандидатов.

Лимит основной кампании, K и N отложены пользователем до результатов отдельного пилота. Поэтому основной журнал не инициализирован и поиск не запускается. Пилот планируется отдельно на 3–5 предложениях, без реального private, для измерения расходов Codex, вычислений и проверки эволюционного цикла. Пилот также не запущен.

# Подготовленные материалы пилота

Производные build-публикации и их каталог в этом пилоте не используются. Повторная подготовка, публикация или проверка читателя не требуется. Существующий baseline и веса передаются штатному CPU DockerRunner оператором; исследователю веса не предоставляются. Их происхождение зафиксировано в cases/ar-03/provenance.json и операторском handoff ../preparation.md; формат и состав метрики описаны в ../metric-description.json. Новые расходы подготовки не создавались и не объявляются нулевыми для неизвестных прежних расходов.

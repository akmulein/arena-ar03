# Запуск десяти сохранённых кандидатов SC35

## Комплект и окружение

Выберите каталог нужного кандидата из [общего списка](README.md). Внутри его `candidate/` находятся `solve.py`, `solution.json`, `assets/` с профилем и таксономией и `runtime/sc35/` со всеми модулями зарегистрированного метода. Для каждого варианта сохранён полный снимок, включая присутствовавшие исторические файлы кеша Python; исходники и кеши при извлечении не менялись. Новый запуск не нужен для просмотра или сравнения кода.

Измеренное окружение использует Python 3.14, `lxml==6.1.3` и `jsonschema==4.26.0`. Все десять `solution.json` выбирают `sc35-content` с пустыми параметрами. Адаптер запускает соответствующий `solve.py`; его устройство и сборка операторского образа описаны в [инструкции харнеса SC35](../../../../../../../cases/sc35/harness/README.md).

## Три формальных и семь гибридных вариантов

`sc35-formal-exp2`, `sc35-formal-exp3` и `sc35-formal-exp4` передают в pipeline `client=None`. Они выполняют граф требований, формальные OOXML-проверки, типографику и свой набор дополнительных проверок, не создают `GatewayClient` и не обращаются к модели. Поля модели и gateway их `solve.py` не читает.

Остальные семь финалистов создают `GatewayClient(payload)` и добавляют содержательный модельный этап. Им нужны закреплённая внутренняя `deepseek-ai/DeepSeek-V4-Flash-0731` с `reasoning_effort=max`, временный scoped gateway и положительный модельный таймаут. Endpoint и полномочия выдаёт оператор; веса и ключ модели в код кандидата не входят. Содержательная инструкция находится в `runtime/sc35/arena/skills/espd-content-review/SKILL.md` соответствующего снимка.

У всех десяти сохранён один внешний контракт зарегистрированного харнеса: запрос с `uses_model=false` отвергается даже формальными вариантами. Для совместимости оставляют штатное `uses_model=true` и выбирают нужный каталог кандидата. Этот флаг разрешает модельный путь харнеса, но у трёх формальных реализаций сам код его не использует; их измеренный модельный расход равен нулю.

## Вход и выход

`solve.py` читает из stdin один JSON-запрос арены. Он содержит `operation=solve`, `uses_model=true` и поле `input` как строку JSON текущего примера. Внутри `input` должны быть ровно `case_id`, `docx_base64`, `document_sha256` и `text_sha256` штатного формата SC35. Гибридные варианты дополнительно читают внешние `model`, `model_base_url` и `model_request_timeout`.

Каждый entrypoint восстанавливает текущий DOCX во временный каталог и проверяет его совместимость с канонической проекцией. Ответ в stdout имеет вид `{"answer":"<сериализованный sc35-span-review-v1>"}`. Ошибка внешнего запроса, импорта или идентичности входа завершает процесс с ненулевым кодом; stderr не раскрывает документ и scoped gateway. Временные секретные адреса не сохраняют в файлах кандидата.

Пример технического вызова из каталога `finalists/` в подготовленном окружении с существующим операторским request-файлом:

```bash
python -E -s -B sc35-sem-v3-exp4-prompt/candidate/solve.py < operator-request.json > result.json
```

Для другого финалиста замените только путь к `solve.py`. Гибридный вариант с живым gateway выполняет реальный модельный запрос; формальный вариант его не делает. Эта команда описывает контракт сохранённого кода и не выполнялась при извлечении. Новую оценку качества проводят отдельным запуском с явно заданными условиями; завершённая private-серия от извлечения файлов не меняется.

## Поведение измеренных версий

Гибриды могут перехватить исключение содержательного этапа и вернуть формальный review. Их собственный флаг `llm_called` после такого возврата способен оставаться `false`, хотя модельный запрос уже состоялся; токены и попытки учитываются доверенным gateway. Технические повторы выполняет gateway, а корректно полученный ответ не запрашивается заново ради балла. Подробности локализации, шаблонных констант и ограничений разобраны в [алгоритме победителя](../winner-sem-v3-exp4-prompt/ALGORITHM.md) и [отчёте кампании](../README.md).

Все десять методов оценены на повреждениях одной исходной ПМИ. Содержимое `candidate/` — исторический измеренный вариант: изменение правила, константы, промпта или обработки ответа создаёт новую версию. Закрытые документы и эталоны, модель, инфраструктура арены и доставка MLflow не являются частью этих снимков.

# AR-03: baseline

Вход — полная страница JPG/PNG. Выход — JSON `tables`, каждая таблица содержит
`bbox`, `rows`, `cols`, `cells`. Индексы включительные, с нуля. Пустые ячейки
обязательны. Прямоугольные объединения задаются интервалами r0:r1, c0:c1.
Дополнительный `bbox` ячеек нужен для визуализации. Все координаты — в пикселях
входного изображения, после обратного преобразования deskew.

CPU: OpenCV → сетка → Tesseract eng. Обучения и внешних моделей нет.
Оценщик импортирует только контракт/сериализацию, не алгоритм baseline.
Arena, кампании и упаковка навыка в текущую реализацию не входят.

# PubTables-1M

Источник: https://huggingface.co/datasets/bsmock/pubtables-1m
Лицензия: CDLA-Permissive-2.0. Метаданные архивов, размеры и SHA256 сохранены
в `docs/upstream/dataset-files.json`.

Цель: 16000 train / 2000 public / 2000 private. Источники — официальные
train / val / test. Manifest фиксирует документ PMC, страницу, официальный
split, seed, параметры искажений и SHA256 готового JPEG. Все данные, включая
private GT, исключены из Git через `data/`.

PDF-аннотации содержат pdf_page_index, pdf_full_page_bbox, pdf_table_bbox,
row_nums, column_nums, pdf_bbox и pdf_text_content. Масштабирование использует
фактическую ширину/высоту полного изображения. Страница исключается целиком,
если хотя бы одна таблица помечена exclude_for_detection/structure или
не проходит строгую проверку полной прямоугольной сетки. Это ограничивает
выборку страницами с пригодной разметкой и может смещать сложность выборки.

Порядок отбора — порядок файлов официального tar, первые N пригодных страниц,
подтверждённых официальным filelist. Это воспроизводимая, но не равномерная
случайная выборка. Seed=42 определяет независимые искажения страницы через
SHA256(seed:page_id); распределение одинаково для каждого split.

Искажения: угол U(-2,2) градуса, масштаб U(.65,1), Gaussian blur sigma U(0,.8),
Gaussian noise sigma U(0,7), JPEG quality integer U[55,95]. Размер уменьшается
один раз, поворот и масштаб объединены affine-матрицей. Bbox вычисляется по
всем четырём углам и ограничивается размером изображения. Ячейки хранят AABB
после поворота; логические rowspan/colspan не меняются.

Архив PDF-аннотаций загружается полностью. Архивы изображений читаются потоком
без сохранения ненужных изображений; после получения N страниц поток закрывается.
Вторая часть train не загружается. Полный SHA256 для частично прочитанного
архива изображений не проверяется; SHA256 каждого извлечённого JPEG сохраняется.
Загрузка по HTTPS с закреплённой ревизией
35b1c097807e0b07ec5313879b85956b7b3890db. PDF/filelists проверяются по SHA256. Повторный запуск перечитывает поток, пропуская готовые id.

Размеры заданы пользователем: 20000 страниц дают полноценный набор для будущей
Arena, но последовательный OCR 18000 страниц может занимать часы.
Private не используется для настройки или измерения baseline.
